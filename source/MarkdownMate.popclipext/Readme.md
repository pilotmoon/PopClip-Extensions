# MarkdownMate PopClip Extension

Create a new note in [MarkdownMate](https://markdownmate.homielab.com/) from the selected text. Formatting such as
headings, bold text and links is converted to Markdown when the source app provides HTML or rich text. Otherwise, the text is sent
unchanged.

The note is created in the folder open in MarkdownMate, or as an untitled note when no folder is open.

Hold Option (⌥) to send the plain text without converting it. This is useful when the selection is already Markdown,
such as Markdown source shown on a web page.
