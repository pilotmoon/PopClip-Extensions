# CamelCamelCamel Extension

A PopClip extension to search [camelcamelcamel](https://camelcamelcamel.com), an Amazon price tracker.

Select an Amazon product code or URL, then click the extension to view its price history.
Choose your Amazon country in the extension's **Country** setting. Supported countries
are Australia, Canada, France, Germany, Italy, Spain, the United Kingdom and the
United States. The default is United States.

Icon: Camel by parkjisun from the Noun Project.
