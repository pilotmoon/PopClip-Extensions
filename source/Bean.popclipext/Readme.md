# Bean PopClip Extension

Create a new document in [Bean](https://www.bean-osx.com/Bean.html) — a small, easy-to-use word processor — containing
the selected text.

## Notes

Author: Nick Moore

Uses Bean's "New Bean Document Containing Selection" macOS Service.

Icon: Based on `coffee-bean-solid` by Streamline (CC-BY-4.0).
