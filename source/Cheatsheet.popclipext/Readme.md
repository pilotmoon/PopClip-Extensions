# Cheatsheet PopClip Extension

Create a new note in [Cheatsheet](https://overdesigned.net/cheatsheet/) from
the selected text.

## Notes

Author: Nick Moore

Uses Cheatsheet's documented [URL scheme](https://overdesigned.net/cheatsheet/support/index.html).

Icon SVG by extension author, traced over app icon.
